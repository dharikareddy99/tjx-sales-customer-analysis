# TJX Sales & Customer Metrics Analysis

## Project Overview

This project analyses retail sales and customer metrics using Excel to understand sales performance, purchasing behaviour, and customer contribution.

The project combines spreadsheet analysis, formulas, PivotTables, and dashboard reporting to turn transaction-level data into meaningful business insights.

## Business Objectives

- Analyse overall sales performance.
- Understand order and product volumes.
- Evaluate customer purchasing behaviour.
- Calculate average order value and average customer spend.
- Present key metrics through a clear dashboard.

## Tools & Techniques

- Microsoft Excel
- PivotTables and Pivot Charts
- SUMIFS
- FILTER and UNIQUE
- INDEX and MIN
- IFERROR
- Dynamic array formulas
- Dashboard design and KPI reporting

## Key Performance Indicators

- Total Sales
- Total Orders
- Total Products
- Total Customers
- Average Order Value (AOV)
- Average Spend per Customer

## Analysis Workflow

1. Review and prepare the source data.
2. Calculate key sales and customer metrics.
3. Build category-level PivotTables.
4. Develop supporting calculations and analysis sheets.
5. Present key metrics in a sales and customer dashboard.

## Business Value

The analysis provides a consolidated view of retail sales and customer metrics, helping stakeholders review performance, compare categories, and identify areas for further investigation.

## Project Files

- Excel workbook containing the analysis, calculated sheet, PivotTables, and dashboard.
- Dashboard screenshots.
- Supporting findings or presentation, where available.

## Conclusion

This project demonstrates practical Excel analytics, formula-based calculations, PivotTable analysis, KPI development, and dashboard reporting for a retail sales use case.
